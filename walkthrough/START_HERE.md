# Watch the RCRD walkthrough

After launching RCRD, select your profile picture → **Help & setup guide** → **Watch walkthrough** to play the 1080p narrated guide inside the app. You can also open **RCRD-complete-walkthrough.mp4** in this folder. It has 19 chapters and runs about 8 minutes 43 seconds. Use full screen for the clearest view; compatible players can jump between chapter markers.

If you prefer reading, open **RCRD-complete-walkthrough-transcript.md**. It includes the narration and official first-time setup links.

The walkthrough records clicks, scrolling, and page changes in RCRD using an example account and music. Setup uses the app's guide and example configuration; private provider sign-in screens are explained rather than filmed.

The `source` folder contains rebuild files and narration. You only need the MP4 to watch the video.
